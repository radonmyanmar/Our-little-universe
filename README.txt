OUR LITTLE UNIVERSE WEBSITE

1. Keep index.html and the assets folder together.
2. Open index.html in a browser to preview.
3. To publish free with GitHub Pages:
   - Create a public GitHub repository.
   - Upload index.html and the whole assets folder.
   - In repository Settings > Pages, choose Deploy from a branch,
     select main and / (root), then Save.
   - Wait for GitHub Pages to publish the site.

The page is mobile-friendly and includes the 3 photos, 5 videos,
a memories gallery, a letter section, and a counter from 03 August 2026.
